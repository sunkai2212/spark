# 火花 · Spark

个人创意数字花园。每一个 App 概念、小程序灵感、工具的雏形，都始于脑海中的一瞬火花。

**线上地址**：[sunkai2212.github.io/spark](https://sunkai2212.github.io/spark/)

## 这是什么

火花是一个用 [Quartz](https://quartz.jzhao.xyz/) 构建的静态站点，用于存放和展示个人应用创意。所有内容以 Markdown 文件存储，Git 管理版本，GitHub Pages 托管。

## 如何添加创意

1. 在 `content/ideas/` 下新建 `.md` 文件
2. 填写 frontmatter 和正文（参考已有的示例）
3. `git add → git commit → git push`
4. 1 分钟后自动上线

## 技术

- Quartz v4.5.2
- TypeScript
- GitHub Pages + GitHub Actions
