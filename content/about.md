> **火花，在熄灭之前被看见。**

这里是 sunka 的创意收集器。每一个 App 概念、小程序灵感、工具的雏形，都始于脑海中的一瞬火花。

这里不追求完美，只追求记录。半成品、碎片想法、一闪而过的念头——都值得被留下，被回顾，被重新点燃。

---

### 关于我

一个对产品有热情的人，相信好的创意来自对日常生活的观察。火花是我和这些想法对话的方式。

### 关于这个站

火花基于 [Quartz](https://quartz.jzhao.xyz/) 构建，托管在 GitHub Pages。所有的创意都以 Markdown 文件存储，用 Git 管理版本。没有数据库，没有后端，只有内容和链接。

如果你也对这个站感兴趣，可以在 [GitHub](https://github.com/sunkai2212/spark) 找到它的源代码。
