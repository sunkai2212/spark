## 灵感来源

微醺状态下说的话，是清醒时说不出口的东西。但打字太累，朋友圈太公共，备忘录太冷。需要一个**什么都不问、只需要你按下按钮说话**的地方。

这不是日记 App，不是语音备忘录，不是一个产品。是一个**情绪出口**——在你刚好有点上头的时候，把话留给夜晚。

## 产品设计

### 极简到只剩一个按钮

打开就是一颗 180px 的琥珀色圆形按钮。按下说话，再按结束。没有标题栏、没有导航、没有列表——只有一个按钮。

录制完成后才出现两件事：**心情**（8 个 emoji）和**喝了什么**（啤酒 / 红酒 / 鸡尾酒 / 白酒 / 烧酒 / 清酒，配上微醺等级 1-5）。都不是必填。

### 暗色 · 琥珀 · 克制

深色背景 `#121212`，琥珀色光晕 `#ea580c`。录制时按钮脉动 + 外发光，像暗夜里的一盏小灯。没有任何多余元素——**你、麦克风、和夜晚**。

## 技术方案

- React 19 + TypeScript + Tailwind CSS v4 + Vite
- Web Audio API（AnalyserNode 实时波形可视化）
- MediaRecorder API（音频采集）
- IndexedDB（idb 封装，本地存储所有录音 + 元数据）
- PWA（standalone 模式 + manifest + 图标）

## 录音数据模型

每条录音记录包含：
- 音频 Blob + MIME 类型 + 时长 + 文件大小
- 心情标签（emoji）
- 饮品上下文（类型 × 微醺等级 1-5）
- 创建时间戳

所有数据仅存储在本地 IndexedDB，不上传、不同步。

## 交互流程

```
打开 → 大按钮 → 按下录音 → 波形 + 计时器
    → 再按结束 → 选心情 → （可选）标注喝了什么
    → 已保存 → 回到初始状态
    → 下滑可看历史记录，点击可回放
```

## 设计哲学

- 输入优先于分类：先说话，再标记
- 元数据是可选的：心情和饮品都可以跳过
- 不可逆的温和感：语音转瞬即逝，不留文字草稿
- 不给任何压力：没有打卡、没有统计、没有"连续记录天数"
