## 灵感来源

手机备忘录里堆了 200 多条零散的笔记，有的是半夜惊醒抓起手机录的一句话，有的是路边看到的有趣招牌随手拍的照。它们都是火花的原料，但实在太散了。

能不能有一个工具，让 AI 帮你整理这些碎片？比如把这周你录的所有语音转录并串联，发现其中的关联，甚至帮你起草一个初步的方案？

## 目标用户

- 创意工作者（设计师、产品经理、写作者）
- 有记录习惯但缺少整理时间的人

## 核心功能

- **多模态输入**：语音转文字、拍照 OCR、网页剪藏、快速打字
- **AI 自动归类**：自动识别主题，将碎片归入对应的"创意项目"
- **周报式回顾**：每周自动生成"本周灵感回顾"，归纳趋势
- **关联发现**：AI 找出不同笔记之间潜在的关联——"这个想法和你三个月前的那条笔记很像"
- **一键生成草案**：选中几段相关笔记，AI 扩展成一篇结构化的创意方案

## 技术方案

- SwiftUI（iOS）+ Next.js（Web）
- Whisper API 语音转文字
- Claude API 做文本理解和关联分析
- 本地 SQLite + iCloud 同步

## 待解决的难点

- 隐私：用户笔记是高度私密的数据，本地处理优先
- 准确率：AI 分类和关联的准确度直接影响体验
- 输入的门槛：如何让随手记录足够简单
